## Связь требований и кода

Документы проектирования сохранены без изменения содержимого. Они описывают раннюю постановку; актуальное состояние отражено в README, архитектуре и исходном коде.

| Тема | Ранняя постановка | Текущая реализация |
| --- | --- | --- |
| Анализ новости | Внешний LLM API | Ollama, готовая модель `llama3.2:3b` |
| Хранение подписок | Ранний PDF описывает память приложения | PostgreSQL |
| Изменение выбора | Подтверждение списка | Каждое нажатие сохраняется сразу; «Готово» показывает результат |
| Остановка рассылки | Отдельный флаг уведомлений | Отключение активных подписок |
| Обработка | Повторяющийся сбор новостей | Последовательный pipeline и настраиваемый планировщик |

Названия участников и организаций внутри оригиналов относятся к контексту постановки задачи. Подтверждённое коммерческое внедрение в репозитории не заявляется.
