# Вспомогательные операции

[init_db.py](init_db.py) читает начальную схему из `database/schema.sql` и создаёт таблицы и компании в уже существующей пустой БД. Он использует общие настройки и подключение из пакета `money_market_alert`.

Скрипт не создаёт PostgreSQL-сервер и не мигрирует существующие данные. Инструкции установки будут добавлены после проверки полного MVP.
