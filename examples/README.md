# Пример уведомления

[demo-news.json](demo-news.json) содержит вымышленную новость NVIDIA и заранее заданный анализ. [demo.py](demo.py) проверяет структуру этого анализа и использует функцию форматирования из основного пакета.

Пример показывает итоговый текст. Он не вызывает модель, не обращается к внешним сервисам и не отправляет сообщение. Значения важности и тональности здесь заданы для демонстрации, а не получены в эксперименте.
